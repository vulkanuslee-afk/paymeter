# 페이미터 (PayMeter)

> 한국 택시 미터기에서 영감을 받은 실시간 급여 계산 앱

일을 시작하면 미터기가 돌아갑니다. 초 단위로 쌓이는 내 수입을 지켜보고, 퇴근할 때 영수증을 받으세요.

## 왜 만들었나

옛날 택시 미터기에는 요금이 오를 때마다 말이 달렸습니다. 그 감각을 노동 시간에 옮겨왔습니다.
알바생도 직장인도, 자기 시간에 값이 있다는 걸 눈으로 보게 하는 것이 이 앱의 목적입니다.

---

## 주요 기능

### 미터기
- 시급 또는 **월 실수령액** 기준 실시간 수입 계산 (초 단위)
- 월급 모드는 실수령액 ÷ 월 소정근로시간(기본 209시간)으로 실질 시급 자동 산출
- 야간(×1.5) · 휴일(×1.5) 가산 옵션
- 7세그먼트 디지털 폰트로 표시되는 시계와 금액

### 달리는 말
- 갤럽 16프레임 애니메이션 (실제 말 영상에서 실루엣 추출)
- 근무 중에만 달리고, 도로와 속도선이 함께 흐름

### 근무 관리
- 퇴근 시간 설정 시 카운트다운 + 알람(소리·진동·화면 표시) + 미터기 자동 종료
- 목표 금액 달성 시 화면 전체 꽃비 축하 효과
- 만원 단위로 쌓일 때마다 현금 소리
- 앱이 강제 종료돼도 근무 시간이 이어짐 (시각 기반 계산)
- 화면 켜짐 유지 옵션

### 퇴근 영수증
- 근무 시간 · 적용 단가 · 총 수입 · 커피/치킨 환산
- **노동에 관한 문구 300개** 중 무작위 출력
- 영수증마다 고유 인증번호 (`PM-260725-0C27TD` 형식)
- 이미지로 저장하거나 바로 공유

### 기록
- 월별 달력에 일자별 수입을 농도로 표시
- 설정과 기록은 기기에만 저장 (외부 전송 없음)

## 빌드 방법

### 요구 사항
- Android Studio (Hedgehog 이상 권장)
- JDK 17 (Android Studio 내장)
- minSdk 21 (Android 5.0) / targetSdk 34

### 실행
```
1. File → Open → 이 폴더 선택
2. Gradle Sync 완료 대기 (최초 1회, 인터넷 필요)
3. Build Variants 탭에서 freeDebug 또는 proDebug 선택
4. ▶ Run
```

### 빌드 변형

하나의 코드베이스로 두 개의 앱을 만듭니다.

| 변형 | 패키지명 | 특징 |
|---|---|---|
| `free` | `com.paymeter.app` | 상단 광고 영역 포함 |
| `pro` | `com.paymeter.pro` | 광고 없음 (유료 배포용) |

앱 본체는 각 변형의 `assets/index.html` 하나에 모두 들어 있습니다.

- `app/src/free/assets/index.html`
- `app/src/pro/assets/index.html`

두 파일은 `const PRO = false / true` 한 줄만 다릅니다. 기능을 수정할 때는 양쪽을 함께 반영하세요.

### 릴리스 빌드 (AAB)
```
Build → Generate Signed Bundle / APK → Android App Bundle
```

서명키(`.jks`)는 **저장소에 커밋하지 마세요.** `.gitignore`에 이미 제외되어 있습니다.
키를 분실하면 스토어 업데이트가 영구히 불가능합니다.

## 구조

```
app/
├── build.gradle                    빌드 설정, free/pro 변형 정의
├── src/main/
│   ├── AndroidManifest.xml
│   ├── java/com/paymeter/app/
│   │   └── MainActivity.java       WebView 실행 + 이미지 저장·공유 브리지
│   └── res/
│       ├── mipmap-*/               앱 아이콘
│       ├── values/styles.xml       다크 테마
│       └── xml/file_paths.xml      FileProvider 경로
├── src/free/assets/index.html      무료판 본체
└── src/pro/assets/index.html       유료판 본체

index.html                          웹 버전 (GitHub Pages가 여기서 서비스)
manifest.json
sw.js                               오프라인 캐시
icon-*.png                          앱 아이콘
```

앱 로직 전체가 단일 HTML 파일 안에 있습니다. 폰트·효과음·애니메이션까지 모두 내장되어 **네트워크 없이 완전히 동작**합니다.

네이티브 코드는 WebView를 띄우고, 영수증 이미지를 갤러리에 저장하거나 공유하는 역할만 합니다.

## 기술 메모

**말 애니메이션** — 실제 말이 달리는 영상에서 프레임을 추출해 실루엣으로 변환했습니다. 갤럽 주기(약 0.65초)를 측정해 자연스럽게 반복되는 16프레임 루프를 만들고, 상체 무게중심을 기준으로 정렬해 제자리 달리기처럼 보이게 했습니다. 실루엣 처리는 상체와 하체를 분리해서 적용합니다 — 상체는 틈을 메워 목이 이어지게, 하체는 그대로 두어 다리가 붙지 않게 하기 위함입니다.

**근무 시간 정확도** — 타이머 누적이 아니라 시작 시각(epoch)을 저장하는 방식이라, 앱이 백그라운드로 밀리거나 시스템에 종료돼도 실제 경과 시간이 정확히 반영됩니다.

**영수증 이미지** — 화면 캡처가 아니라 Canvas에 직접 그립니다. 화면 크기와 무관하게 일정한 고해상도 결과물이 나옵니다.

## 웹에서 바로 사용하기

설치 없이 브라우저에서 바로 쓸 수 있습니다.

**https://vulkanuslee-afk.github.io/paymeter/**
