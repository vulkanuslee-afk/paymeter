# 깃허브에 올리는 방법

처음이시라면 순서대로 따라 하시면 됩니다. 10분이면 끝납니다.

---

## 0. 먼저 결정할 것 — 공개 vs 비공개

앱을 **유료로 판매할 계획이라면 비공개(Private) 저장소를 권합니다.**
공개 저장소에 올리면 누구나 코드를 받아 빌드할 수 있습니다.

- **비공개**: 백업·버전 관리 목적 (무료 계정도 가능, 개수 제한 없음)
- **공개**: 포트폴리오로 보여주고 싶을 때

비공개로 시작해서 나중에 공개로 바꿀 수 있습니다. 반대는 되돌리기 어렵습니다.
자세한 판단 기준은 [`LICENSE-OPTIONS.md`](LICENSE-OPTIONS.md)에 정리해 두었습니다.

## 방법 A. Android Studio에서 바로 올리기 (가장 쉬움)

Git을 따로 설치할 필요가 없습니다.

1. Android Studio에서 프로젝트를 엽니다
2. 상단 메뉴 **Git → GitHub → Share Project on GitHub**
3. GitHub 계정 로그인 (처음 한 번만)
4. 저장소 이름 입력 (예: `paymeter`)
5. **Private 체크박스**를 상황에 맞게 설정
6. Share 클릭 → 올릴 파일 목록이 뜨면 확인 후 Add

끝입니다. 이후 수정할 때는 **Git → Commit** → **Git → Push**만 하면 됩니다.

## 방법 B. 명령어로 올리기

Git이 설치되어 있어야 합니다. ([git-scm.com](https://git-scm.com))

### 1. GitHub에서 빈 저장소 만들기
github.com → 우측 상단 **+** → **New repository**
- 이름: `paymeter`
- Public / Private 선택
- **README, .gitignore, license는 추가하지 마세요** (이미 프로젝트에 있습니다)

### 2. 프로젝트 폴더에서 실행

```bash
cd 프로젝트폴더

git init
git add .
git commit -m "페이미터 최초 커밋"
git branch -M main
git remote add origin https://github.com/사용자명/paymeter.git
git push -u origin main
```

`사용자명` 부분을 본인 GitHub 아이디로 바꾸세요.

### 3. 이후 수정할 때

```bash
git add .
git commit -m "무엇을 바꿨는지 적기"
git push
```

## 올라가지 않는 파일들

`.gitignore`에 의해 아래는 자동으로 제외됩니다. 정상입니다.

- `build/`, `.gradle/`, `.idea/` — 빌드하면 다시 생성되는 것들
- `local.properties` — 각자 PC의 SDK 경로
- `*.jks`, `*.keystore` — **서명키**
- `*.apk`, `*.aab` — 빌드 결과물

### 서명키는 절대 올리지 마세요

앱 서명키(`.jks`)가 유출되면 다른 사람이 내 앱을 사칭한 업데이트를 만들 수 있습니다.
반대로 **잃어버리면 스토어 업데이트가 영구히 불가능합니다.**

저장소가 아니라 아래 같은 곳에 따로 백업하세요.
- 비밀번호 관리자 (1Password, Bitwarden 등)
- 암호화된 외장 저장소
- 개인 클라우드의 비공개 폴더

## 자동 빌드 (선택)

`.github/workflows/build.yml`이 포함되어 있어, 코드를 푸시할 때마다 GitHub이 자동으로 빌드를 시도합니다.

- 빌드 성공/실패를 저장소 **Actions** 탭에서 확인
- 빌드된 APK를 그 화면에서 내려받을 수 있음
- 폰이나 PC 없이도 앱이 정상 빌드되는지 검증 가능

필요 없다면 `.github` 폴더를 삭제하세요.

## 스크린샷 추가하기

README 상단에 앱 화면이 보이면 훨씬 좋습니다.

1. 폰에서 앱 실행 → 세로·가로 화면 캡처
2. 파일명을 아래처럼 바꿔서 `docs/` 폴더에 넣기
   - `docs/screenshot-portrait.png`
   - `docs/screenshot-landscape.png`
3. 커밋 후 푸시

README에 이미 해당 경로가 연결되어 있어, 파일만 넣으면 바로 표시됩니다.

## 자주 겪는 문제

**`git push`에서 인증 실패**
GitHub은 비밀번호 대신 토큰을 씁니다.
Settings → Developer settings → Personal access tokens → Generate new token (classic) → `repo` 권한 체크 → 생성된 토큰을 비밀번호 자리에 입력하세요.

**파일이 너무 많이 올라감**
`.gitignore`가 제대로 적용되지 않은 경우입니다. 이미 커밋했다면:
```bash
git rm -r --cached .
git add .
git commit -m ".gitignore 적용"
```

**한글 파일명이 깨져 보임**
```bash
git config --global core.quotepath false
```
