# GitHub Pages 설정하기

앱의 웹 버전을 인터넷에 올려서, 아이폰 사용자도 설치할 수 있게 만드는 방법입니다.

완성되면 이 주소로 접속할 수 있습니다:

```
https://vulkanuslee-afk.github.io/paymeter/
```

---

## 1단계. 커스텀 도메인 오류부터 해결

지금 저장소에 이런 빨간 오류가 떠 있습니다.

> The custom domain `ppayymmetter` is not properly formatted.

**원인:** Custom domain 칸에 `ppayymmetter`를 입력하셨는데, 이 칸은 **직접 구매한 진짜 도메인**을 넣는 곳입니다. `paymeter.com`처럼 `.com`, `.kr` 같은 뒷부분이 반드시 있어야 해요.

**해결:**
1. Settings → Pages → **Custom domain** 칸을 완전히 비웁니다
2. 옆의 **Save** 를 누릅니다 (Remove 버튼이 있다면 그것도 가능)
3. 빨간 오류가 사라집니다

도메인을 따로 사지 않으셨다면 이 칸은 **영원히 비워두시면 됩니다.** 기본 주소가 자동으로 제공됩니다.

---

## 2단계. Source 확인

Settings → Pages → **Build and deployment → Source**

- **`GitHub Actions`** 로 되어 있으면 그대로 두세요 (이미 맞게 설정되어 있습니다)

이 저장소에는 `.github/workflows/pages.yml` 이 들어 있어서, 코드를 올리면 자동으로 웹사이트가 배포됩니다.

---

## 3단계. 파일 올리기

`web/` 폴더를 저장소에 올립니다.

```bash
git add .
git commit -m "웹 버전 추가"
git push
```

Android Studio를 쓰신다면 **Git → Commit → Push** 로 하셔도 됩니다.

---

## 4단계. 배포 확인

1. 저장소 상단 **Actions** 탭 클릭
2. `Deploy Pages` 작업이 실행 중(노란 점) → 완료(초록 체크) 될 때까지 1~2분 기다립니다
3. Settings → Pages 로 돌아가면 상단에 주소가 표시됩니다

주소가 안 뜨면 Actions 탭에서 오류 메시지를 확인하세요.

---

## 아이폰에 설치하기

주소가 생기면 아이폰에서:

1. **사파리**로 주소 접속 (크롬 아님 — 사파리여야 합니다)
2. 하단 **공유 버튼(⬆️)** 탭
3. **홈 화면에 추가** 선택

홈 화면에 네온 ₩ 아이콘이 생기고, 전체화면 앱처럼 열립니다. 한 번 열어두면 **비행기 모드에서도 작동**합니다.

안드로이드 크롬에서도 같은 방식으로 설치할 수 있습니다.

---

## 플레이스토어 AAB에 대해

전에 "netlify에 올려서 PWABuilder로 AAB를 만들라"고 안내드렸는데, **이제 그럴 필요가 없습니다.**

Android Studio 정식 프로젝트가 있으니 거기서 바로 AAB를 만드는 게 낫습니다.

```
Android Studio → Build → Generate Signed Bundle / APK → Android App Bundle
```

네이티브 프로젝트로 만든 AAB가 PWABuilder 결과물보다 안정적이고, 알람·진동·이미지 저장 같은 기능도 제대로 동작합니다.

## 판매 전략에 관한 참고

저장소가 **공개**이고 웹 버전도 무료로 공개되므로, 이런 상황이 됩니다.

| | 접근성 | 비용 |
|---|---|---|
| 웹 버전 (Pages) | 누구나 브라우저로 | 무료 |
| 안드로이드 무료판 | 플레이스토어 | 무료 + 광고 |
| 안드로이드 유료판 | 플레이스토어 | 2,000원 |

**웹 버전이 무료인데 왜 2,000원을 낼까?** 라는 의문이 생길 수 있습니다. 실제로는 이렇게 작동합니다.

- 대부분의 사용자는 브라우저 북마크보다 **앱 설치를 선호**합니다
- 네이티브 앱은 알람 신뢰성, 백그라운드 동작, 진동이 더 안정적입니다
- 웹 버전은 **체험판 역할**을 해서 오히려 유입을 늘립니다
- 아이폰 사용자는 어차피 안드로이드 앱을 살 수 없으니, 웹이 유일한 통로입니다

이 방식이 부담스럽다면 선택지가 있습니다.

1. **웹은 기능 축소판으로** — `web/index.html`에서 영수증이나 달력을 빼고 배포
2. **저장소를 비공개로** — 단, GitHub Pages는 무료 계정에서 공개 저장소만 지원합니다
3. **지금처럼 전체 공개** — 웹을 마케팅 채널로 활용

현재는 3번(광고 없는 전체 기능)으로 설정되어 있습니다.

## 웹 버전 수정하기

앱을 수정했다면 웹 버전도 같이 갱신해야 합니다.

1. `app/src/pro/assets/index.html` 의 변경 내용을 `web/index.html` 에도 반영
2. `web/sw.js` 의 `const CACHE='paymeter-v1'` 에서 숫자를 올립니다 (`v2`, `v3`...)
   - 이렇게 해야 기존 방문자에게 새 버전이 전달됩니다
3. 커밋 후 푸시 → 자동 배포

## 문제 해결

**Actions에서 배포가 실패해요**
Settings → Actions → General → Workflow permissions 에서 **Read and write permissions** 가 선택되어 있는지 확인하세요.

**주소는 뜨는데 404가 나요**
`web/index.html` 파일이 실제로 저장소에 올라갔는지 확인하세요. GitHub 웹에서 `web` 폴더를 열어보면 바로 알 수 있습니다.

**수정했는데 예전 화면이 나와요**
브라우저 캐시 또는 서비스워커 때문입니다. `web/sw.js` 의 캐시 버전(`paymeter-v1` → `v2`)을 올리고 다시 배포하세요.

**아이폰에서 "홈 화면에 추가"가 안 보여요**
크롬이 아니라 **사파리**로 접속해야 합니다.
